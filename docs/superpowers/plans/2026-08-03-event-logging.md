# Event logging — implementation plan

> **For agentic workers:** Use superpowers:subagent-driven-development or superpowers:executing-plans.

**Goal:** Structured logging at Info/Debug/Verbose, rolling daily files, a Save
Logs control — carrying no user data at any level.

**Spec:** `docs/superpowers/specs/2026-08-03-event-logging-design.md`. Read it
first; §2 and §6 are the design.

**Tech Stack:** `tracing`, `tracing-subscriber`, `tracing-appender`; Tauri 2;
React 19 + TypeScript.

## Global Constraints

- **No user data in any log line, at any level.** No paths, file names, process
  names, addresses, prompts, or model output. This is the point of the feature.
- **No `unwrap()`/`expect()`/`panic!()` outside `#[cfg(test)]`.** Tests opt out
  with exactly `#![allow(clippy::unwrap_used, clippy::expect_used)]`. **Never
  add `clippy::panic`** — the workspace sets it to `warn` and CI runs
  `-D warnings`, so `panic!` and `assert!(false, …)` fail the build even in
  tests. Use paired `assert!`s.
- **`git commit -s`** (DCO), conventional-commit prefix, no co-author or
  "generated by" trailers, **Bash heredocs** for multi-line commit messages.
- **`just ci` must pass**; `just bindings` must leave no diff.
- Crates keep `#![forbid(unsafe_code)]` except `osstat-platform`.

## Task 1: Error kinds

**Files:** `crates/osstat-core/src/error.rs`, `crates/osstat-inference/src/error.rs`,
`crates/osstat-chat/src/error.rs`, and any other error enum in the workspace
(find them with `grep -rn "thiserror::Error" crates/ src-tauri/`).

**Produces:** `pub const fn kind(&self) -> &'static str` on every error enum.

Why: an error's `Display` carries user data. `ChatError::SpawnFailed(String)`
holds `llama-server`'s stderr, which contains paths; `AcquireError` variants
hold file names. Logging the error would leak both, on the code path most
likely to be logged.

- [ ] **Step 1: Write the failing tests.** One per error enum:

```rust
    #[test]
    fn every_variant_has_a_distinct_kind() {
        // A copied-and-not-edited string makes two different failures look
        // identical in a log, which is worse than no log line.
        let kinds = [
            ChatError::NoRuntime.kind(),
            ChatError::NeverReady.kind(),
            ChatError::StreamBroken.kind(),
            ChatError::Cancelled.kind(),
            // ... every variant, constructed cheaply
        ];
        let mut seen: Vec<&str> = Vec::new();
        for kind in kinds {
            assert!(!seen.contains(&kind), "duplicate kind {kind}");
            assert!(!kind.is_empty());
            seen.push(kind);
        }
    }

    #[test]
    fn a_kind_carries_no_user_data() {
        // The whole reason kind() exists: the Display of this variant contains
        // a path, and the kind must not.
        let error = ChatError::ModelUnreadable("/home/someone/secret.gguf".into());
        assert_eq!(error.kind(), "model_unreadable");
        assert!(!error.kind().contains('/'));
    }
```

- [ ] **Step 2: Run and see them fail.** `cargo test --workspace`
- [ ] **Step 3: Implement.** `match self { … }` with `&'static str` snake_case
      names. **No wildcard arm** — a new variant must fail to compile rather
      than silently logging as `unknown`.
- [ ] **Step 4: Tests + `cargo clippy --workspace --all-targets --all-features -- -D warnings` + `cargo fmt --all --check`.**
- [ ] **Step 5: Commit** `feat(logging): give every error a loggable kind`

## Task 2: The logging module

**Files:** Create `src-tauri/src/log.rs`; modify `src-tauri/src/lib.rs`,
`src-tauri/Cargo.toml`.

**Produces:**

- `pub enum LogLevel { Info, Debug, Verbose }` (serde camelCase, `ts-rs`)
- `pub fn init(dir: &Path, level: LogLevel) -> Option<WorkerGuard>`
- `pub fn set_level(level: LogLevel)`
- Event functions taking **only** counts, durations, enum kinds and booleans.

**The critical constraint:** no function in this module may accept `String`,
`&str`, `Path` or `PathBuf` **except** a `&'static str` kind from Task 1. A path
cannot be logged because there is nowhere to put one. Suggested surface:

```rust
pub fn app_started(probe_gpus: usize) {}
pub fn session_started(gpu_layers: u32, context_length: u32) {}
pub fn session_failed(kind: &'static str) {}
pub fn download_finished(bytes: u64, seconds: u64) {}
pub fn download_failed(kind: &'static str) {}
pub fn ui_event(kind: UiEventKind) {}
```

Add whatever else the call sites need, following the same rule.

Use `tracing_subscriber` with an `EnvFilter` and a reloadable layer so
`set_level` works without restarting. `tracing_appender::rolling::daily` writes
to `dir`. **Keep the `WorkerGuard` alive for the process lifetime** — dropping
it loses buffered lines, which would make the last moments before a crash the
part that goes missing.

`warn` and `error` must pass at every setting: build the filter as
`level.max(WARN)` rather than a flat level.

- [ ] **Step 1: Write the failing tests**

```rust
    #[test]
    fn warnings_survive_the_quietest_setting() {
        // An error the user did not opt into is the one they most need.
    }

    #[test]
    fn a_higher_setting_does_not_leak_into_a_lower_one() {}

    #[test]
    fn nothing_emitted_looks_like_user_data() {
        // A net under the module boundary, not a guarantee -- see spec §9.
        // Catches the realistic breakage: a struct that grew a path field and
        // is logged with {:?}.
        let lines = capture_all_log_output();
        for line in lines {
            assert!(!line.contains('/') && !line.contains('\\'), "path-like: {line}");
            assert!(!line.contains('@'), "address-like: {line}");
            assert!(
                !line.chars().collect::<Vec<_>>().windows(6).any(|w| w.iter().all(char::is_ascii_digit)),
                "long digit run: {line}"
            );
        }
    }
```

Timestamps contain digits and colons — configure the subscriber's formatter to
omit timestamps in tests, or strip the prefix before scanning, and say which you
did in a comment.

- [ ] **Step 2: Run and see them fail.**
- [ ] **Step 3: Implement.**
- [ ] **Step 4: Prove the scan test.** Add a temporary function logging a real
      path, confirm `nothing_emitted_looks_like_user_data` FAILS, paste the
      output, remove it, confirm green. **Mandatory** — this test is the net and
      an untested net is decoration.
- [ ] **Step 5: Gate. Step 6: Commit** `feat(logging): add levelled logging to rolling daily files`

## Task 4: Call sites

**Files:** `src-tauri/src/lib.rs`, `sampler.rs`, `runtime.rs`, `chat.rs`,
`models.rs`, `main.rs`.

- [ ] Replace the four `println!`/`eprintln!` calls with `log::` functions.
- [ ] Add logging at: app start, GPU probe result (**as a count**), session
      start/stop/failure, download start/finish/failure, library move,
      conversation save failure, tray actions.
- [ ] **Every error is logged via `kind()`, never `Display` and never `{:?}`.**
      Verify with `grep -rn "error)\|{error}\|{:?}" src-tauri/src/log.rs` — the
      module must not format an error value at all.
- [ ] Sampler ticks log at **trace** only. Info-level per-tick logging on a
      monitoring app would write continuously all day.
- [ ] Gate, then commit `feat(logging): report lifecycle events through the log`

## Task 5: Settings UI

**Files:** `ui/src/pages/Settings.tsx`, `ui/src/pages/Settings.logging.test.tsx`.

Read `src-tauri/src/log.rs` and the regenerated bindings for real command and
field names before writing tests. Follow the existing Settings sections.

- [ ] A level selector (Info / Debug / Verbose) with one line each on what it
      captures, and a note that Verbose is for reproducing a problem rather than
      leaving on.
- [ ] A **Save logs** control opening a folder picker.
- [ ] A line stating plainly that logs contain no personal data and are safe to
      attach to a bug report. That is the user-visible payoff of §2 and it
      should be said where someone deciding whether to share a log will read it.
- [ ] Tests assert on **content**, not presence — a test that only checks a
      selector exists would pass with the levels reversed.
- [ ] **Prove one test by deliberate breakage** (swap two level labels), paste
      the failure, restore.

      `ui/package.json` unchanged.
